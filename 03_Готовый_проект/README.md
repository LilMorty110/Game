# Аварийный выход

Консольная игра на C++ версии Junior. Техник оказывается заперт на подземной станции после аварии. Чтобы выбраться на поверхность, нужно открыть три двери, решая головоломки разных типов.

Группа: **ИСП-3,4**  
Выполнили: **Емелев Никита Александрович, Ананина Кира Алексеевна**.

## Запуск игры

1. Скачайте проект через **Code → Download ZIP** и распакуйте его.
2. Оставьте `Game.exe`, `run_game.cmd` и файлы `loc1.txt`–`loc4.txt` в одной папке.
3. Запустите `run_game.cmd` в Windows.
4. На начальном экране нажмите любую клавишу.

Для запуска готового EXE установка Python, Visual Studio и дополнительных библиотек не нужна.

## Управление

Цифры нажимаются **без Enter**.

| Клавиша главного меню | Действие |
|---|---|
| 1 | Выбрать соседнюю локацию |
| 2 | Показать карту текущей локации |
| 3 | Показать доступные переходы |
| 0 | Завершить игру |

После выбора пункта 1 нажмите номер комнаты из списка. Если дверь закрыта, появится головоломка с вариантами ответа. Нажмите номер ответа. Клавиша 0 отменяет выбор комнаты или решение головоломки. Сообщения остаются на экране до нажатия любой клавиши.

На карте `#` обозначает стену, `.` — пол, `@` — игрока, `D` — дверь. Перемещение происходит между локациями.

## Локации

| Номер | Название | Начальное состояние | Головоломка |
|---|---|---|---|
| 1 | Диспетчерская | Открыта | Нет |
| 2 | Генераторная | Закрыта | Арифметический пример |
| 3 | Архив станции | Закрыта | Расшифровка слова |
| 4 | Выход на поверхность | Закрыта | Логическая задача |

Связи комнат: `1 <-> 2 <-> 3 -> 4`. Верный ответ открывает комнату до конца текущей игры. Попадание в комнату 4 завершает игру победой.

## Сборка из исходного кода

Требуется Visual Studio 2022 с компонентом **Разработка классических приложений на C++** и Windows SDK.

1. Откройте `Game.sln`.
2. Выберите конфигурацию **Release** и платформу **x64**.
3. Выполните **Сборка → Собрать решение**.
4. Запускайте игру из папки проекта через `run_game.cmd`.

В командной строке разработчика Visual Studio можно собрать так:

```bat
cl /EHsc /std:c++17 /utf-8 /MT Game.cpp /Fe:Game.exe
```

## Файлы проекта

- `Game.cpp` — весь исходный код, четыре класса и функции программы.
- `loc1.txt`–`loc4.txt` — ASCII-карты локаций.
- `Game.exe` — готовая сборка для Windows x64.
- `run_game.cmd` — запуск с правильной рабочей папкой и кодировкой.
- `Game.sln`, `Game.vcxproj`, `Game.vcxproj.filters` — проект Visual Studio.
- [Документация](Документация.docx) — поля и методы каждого класса, входные данные, алгоритм и инструкция пользователя.
- `.gitignore` — исключение временных файлов Visual Studio и сборки.

## Проверка

Проверены сборка Release x64, прохождение до победы, неверный ответ, отмена головоломки, недоступный переход, возврат в открытую комнату и очистка экрана при смене сцен. Карты загружаются из TXT-файлов. При отсутствии карты программа сообщает имя недостающего файла.
